By default, Refresh Me's responses come from a small set of built-in, offline replies — nothing ever leaves this device. Adding your own Anthropic API key switches to real AI-generated advice, tailored to exactly what you write. This sends the text you type to Anthropic's API when you do.

🔔 Background alerts

By default, task alarms only fire while this app is open. To get alerts even with the app fully closed, you need to run a small free server (see the project's README for setup) and point the app at it here. Turning this on sends your task titles and due times — not habit or period data — to that server so it knows when to alert you.
